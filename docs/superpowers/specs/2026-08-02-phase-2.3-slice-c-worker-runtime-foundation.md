# Phase 2.3 Slice C — Mac Worker Runtime Foundation

状态：冻结实施规格
目标设备：Apple Silicon M4 / arm64
基线：已通过实机安装与验证的 Mac Core 2.3.0 Slice B

## 1. 目标

建立独立于 REST API 进程的 Mac Worker Runtime，使明确支持的本地任务能够从 `Queued` 安全进入 `Running`，并以租约、心跳和所有权保护写入终态。

本切片只提供执行基础和一个无副作用的 `system.noop` 处理器，不执行历史 `analysis` 任务，不接入 Provider，不上传数据，不产生费用。

## 2. 进程边界

- API：`picotoopet-core serve`
- Worker：`picotoopet-core worker --once|--loop`
- 两者共享 SQLite，但使用独立进程和独立生命周期。
- Worker 默认不随 Slice B 安装启动；后续 Worker 安装包必须显式启用用户级 LaunchAgent。
- API 读取 Worker 原子状态文件，不通过导入或线程方式隐式启动 Worker。

## 3. 安全领取

`lease_next` 必须接收 `supported_task_types`，SQL 只选择明确支持的任务类型。

因此：

- `system.noop` 可以被当前基础 Worker 领取；
- 既有 `analysis` 任务保持 `Queued`；
- 未注册任务类型不会被领取，也不会被自动标记失败；
- 空支持列表不得退化为“领取所有任务”。

## 4. 租约与所有权

领取任务时必须：

- 原子写入 `Running`、`lease_owner`、`lease_expires_at`；
- 增加 `attempt_count`；
- 创建一条 `task_attempts` 运行记录；
- 写入不可变任务事件和 Outbox 更新。

Worker 只能对自己持有的运行任务执行：

- `renew_lease`；
- `complete_leased`；
- `fail_leased`。

所有权不匹配、任务已取消或租约失效时必须拒绝写入。

## 5. 心跳与状态

Worker 每次启动、空闲、执行、降级和停止时更新：

```text
state/worker-status.json
```

写入必须使用临时文件 + 原子替换。公共状态包含：

- schema_version
- available
- state
- reason
- worker_id
- supported_task_types
- active_task_id
- last_heartbeat_at
- observed_at

API 将状态文件映射到 `/api/v1/workers/status`：

- 文件不存在：`not_deployed`
- 心跳新鲜：`online`
- 心跳过期：`offline`
- 文件损坏：`degraded`

## 6. 执行处理器

处理器通过显式注册表加载，不允许动态扫描或任意导入。

本切片仅注册：

```text
system.noop
```

它只验证 payload、返回确定性摘要并完成任务，不访问网络、模型、文件系统或 Provider。

## 7. 失败与恢复

- 处理器异常：当前 Worker 按所有权写入 `Failed`，保留错误码和脱敏错误消息。
- Worker 崩溃：租约过期后由恢复流程转入 `Retrying` 或达到上限后 `Failed`。
- Worker 不能把不属于自己的任务写入终态。
- 取消后的任务不得被完成覆盖。

## 8. CLI

新增：

```text
picotoopet-core worker --once
picotoopet-core worker --loop
```

默认命令不启动 Worker。`--once` 最多领取并处理一个任务；`--loop` 按配置轮询。

## 9. 安装事故继承门

Worker 包必须继承：

- Windows 严格 UTF-8 JSON 门；
- Mac `Application Support` 空格路径门；
- M4/arm64 原生 CI；
- 用户机器无源码构建；
- 成功 Artifact 与 DIAGNOSTIC Artifact 分离；
- 安装、验证、回滚报告；
- 数据库、Token、端口、日志和旧版本保留。

## 10. 本切片完成条件

- 仓储支持任务类型过滤、租约续期和所有权终态；
- Worker Runtime 和原子状态存储完成；
- `system.noop` 端到端通过；
- 未支持的历史任务保持 `Queued`；
- API 状态能区分 not_deployed/online/offline/degraded；
- CLI `worker --once` 通过；
- 全量 Python 回归、Ruff、arm64 原生 CI 通过；
- 在用户 Mac 安装前仍不自动启用 Worker。
