# Phase 2.3 Slice A — Control Center Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the capability-aware Windows Control Center shell, preserve the proven 2.2 connection/event path, and publish machine-checkable Connector/Handoff contract fixtures without implementing later-phase runtimes.

**Architecture:** Extend Mac Core with a backward-compatible capability response, add versioned contract artifacts, then extract the Windows connection/task synchronization from the monolithic window ViewModel into focused stores and a session coordinator. A new WPF shell hosts real legacy connection/task data plus explicit empty states for unavailable capabilities.

**Tech Stack:** Python 3.12, FastAPI, Pydantic, pytest, JSON Schema Draft 2020-12, .NET 10, C# 14, WPF, PowerShell 5.1 compatibility, GitHub Actions `windows-2025`.

## Global Constraints

- Base commit is `4ef2634ec24666d8995874d44bbf5b0e238d450a`.
- Work only in an isolated worktree created from `feature/phase-2.3-control-center-design`.

- Do not implement Generic Connector runtime, Media Worker, Handoff export, Dev Broker or Provider Adapter.

- All new code uses clear, aligned Chinese comments.
- No new third-party Windows test framework; extend the existing zero-package smoke harness.
- Any unsupported native platform verification is reported as `not_run`.
- Every task ends with focused tests and a commit.
