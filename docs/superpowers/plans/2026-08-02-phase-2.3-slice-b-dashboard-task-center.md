# Phase 2.3 Slice B — Dashboard and Task Center Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Task Center placeholder with real durable-queue data, expose truthful Worker availability, provide safe cancel/retry actions, and publish a new native-Windows prebuilt candidate.

**Architecture:** Mac Core remains the only source of truth. It adds a read-only Worker status contract but does not start a Worker. Windows adds a focused Worker state store and a Task Center presentation layer over existing task snapshots and REST actions. Unsupported execution remains visibly unavailable rather than simulated.

**Tech Stack:** Python 3.12, FastAPI, Pydantic, SQLite, pytest, .NET 10, C# 14, WPF, PowerShell 5.1, GitHub Actions `windows-2025`.
