# Phase 2 双机性能与可靠性 SLO

## 原则

性能验收不得依靠删除功能、跳过审计、降低 SQLite 耐久性或绕过权限。所有报告必须给出 p50、p95、p99 和最大值，平均值只能作为补充。

## 有线千兆局域网目标

| 指标 | p50 | p95 | p99 |
|---|---:|---:|---:|
| Mac Health | 20 ms | 50 ms | 100 ms |
| 创建任务确认 | 30 ms | 80 ms | 150 ms |
| WebSocket Ping 往返 | 20 ms | 50 ms | 120 ms |
| 任务创建到桌面收到事件 | 80 ms | 150 ms | 300 ms |

## Windows 交互目标

- 点击后视觉反馈：p95 不超过 100 ms。
- 已缓存页面切换：p95 不超过 100 ms。
- 普通页面切换：p95 不超过 200 ms。
- 热启动到可操作：不超过 1.5 秒。
- 冷启动到可操作：不超过 3.5 秒。
- 网络和磁盘 I/O 阻塞 UI 线程：0 次。

## 恢复目标

- 异常连接识别：不超过 2 秒。
- 自动开始重连：不超过 500 ms。
- 网络恢复后重新在线：p95 不超过 5 秒。
- 断线期间任务状态丢失：0。
- 重复业务副作用：0。

## 测试条件

- 实机性能门使用 Windows 11、Mac mini、同一局域网和至少 500 个样本。
- Wi-Fi 结果单独报告，不用无线干扰掩盖代码问题。
- 大文件传输另测基准吞吐，不进入本切片的 WebSocket 指标。
